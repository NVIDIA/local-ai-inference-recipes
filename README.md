# Local AI Inference Recipes

Validated configurations for running Local AI models on NVIDIA GPUs, each
independently validated, pinned to a tested software stack, and backed by
measured performance on the exact hardware named.

## Browse recipes

Browse the live site at
[nvidia.github.io/local-ai-inference-recipes](https://nvidia.github.io/local-ai-inference-recipes/),
or open `docs/index.html` locally in a browser — `docs/` is a self-contained
static site (GitHub Pages is configured to build from this folder on
[github.com/NVIDIA/local-ai-inference-recipes](https://github.com/NVIDIA/local-ai-inference-recipes)).

## Recommended configurations

`recommended_catalog.json` lists a curated set of standout recipes, grouped
by backend and operating system.
